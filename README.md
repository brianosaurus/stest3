# React Hello World

A minimal React application scaffolded with Vite that renders a "Hello, World"
greeting.

## Prerequisites

- Node.js and npm installed.

## Install

```bash
npm install
```

## Development

Start the Vite dev server with hot module reloading:

```bash
npm run dev
```

Then open the printed local URL (typically `http://localhost:5173`) in a
browser and confirm the greeting text is displayed with no console errors.

## Build

Produce a production build in `dist/`:

```bash
npm run build
```

## Test

Run the test suite once (non-watch mode) with Vitest:

```bash
npm test -- --run
```
